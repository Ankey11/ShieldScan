    ShieldScan

    v1.0.0 — Advanced File & Malware Identifier

    A lightweight, powerful static analysis tool to detect Extension Spoofing and cross-reference files using digital fingerprints (SHA-256) and 60+ antivirus engines via VirusTotal.

    🔍

    Magic Byte Validation

    Inspects raw binary headers to determine a file's true identity, ignoring deceptive extensions.

    🧬

    Cryptographic Hashing

    Generates unique SHA-256 fingerprints using memory-efficient chunk reading for any file size.

    🌐

    VirusTotal Integration

    Scans files across 60+ antivirus engines via hashes — no file upload needed.

    📁

    Batch Directory Scan

    Recursively traverses folders to audit entire file systems in one operation.
